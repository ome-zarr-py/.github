# OME-zarr-py

Welcome to the home of the ome-zarr-py organization.
This project operates as a functional subunit within the [OME open microscopy consortium](https://www.openmicroscopy.org/).
We focus on developing and maintaining the Python implementation of the OME-Zarr format,
ensuring compatibility, performance, and ease of use for the scientific imaging community.

## Relationship to OME

The ome-zarr-py project is a group of implementations registered under the [OME-owned implementations](https://github.com/ome/governance/pull/7) of the NGFF project.
